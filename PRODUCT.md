# BooBar

A small native macOS 27 menu-bar utility for Marco. Two separators define three zones: always hidden, temporary, always visible. The main : marker reveals temporary icons on hover; right click opens settings. Command+Shift-drag arranges icons. The secondary | appears with expanded/arranging icons. Settings request Accessibility, support native login registration, restore all/reset and quit. Preserve identifiers, signing identity, icon assignments, Nivo's signing-identity compatibility, and the existing app icon.

BooB is the approved mascot: B-o-o-B, two central eyes and hands that play peekaboo. User requests native vector articulation, independent hands and eyes, and a SecureCopy-like interface. Reference source: ../SecureCopy_/SecureCopy/appearance.css. This pinned visual direction overrides generic alternatives. Settings are an Operate surface, implemented in SwiftUI/AppKit, without extra runtime dependencies.
